# Landing Page Dr. Cassiano Veronezi

Landing page de alta conversão para o Dr. Cassiano Veronezi, Ortopedista e Traumatologista em Cascavel/PR.

## Tecnologias
- HTML5
- Tailwind CSS
- Lucide Icons
- JavaScript (interações básicas e animações suaves)

## Estrutura do Projeto
- `index.html`: Página principal com todas as seções (Hero, Serviços, Sobre, Depoimentos, FAQ, Footer).
- `imgs/`: Pasta contendo os ativos visuais e logotipos.

## Como publicar
Este projeto está pronto para ser hospedado no **Cloudflare Pages**. Basta conectar o repositório do GitHub à plataforma e o deploy será automático.
